# Employee-Management-System
a Full Stack Employee Management System where admins can add, update, delete, and view employee details. Employees should be able to log in, view their profiles, and update limited details. Choose any frontend and backend stack from the provided options.
Prerequisites:
- Frontend: React.js 
- Backend: Node.js 
- Database: MongoDB 

Tools Required:
- VS Code 
- Postman for API Testing
- Database Client  MongoDB Compass
